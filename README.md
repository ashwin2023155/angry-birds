Developed a full-featured Angry Birds-style game using Java and the libGDX framework, implementing object-oriented
programming (OOP) principles to structure gameplay elements such as birds, obstacles, and projectiles. Integrated 
a custom physics engine to simulate realistic motion, gravity, and collision detection. Added audio effects for 
interactions and events, enhancing user immersion. Ensured dynamic viewport scaling to adapt seamlessly across 
various screen sizes and resolutions, maintaining visual consistency and smooth performance.
